\section{Quadratic Formula}

The quadratic formula for solving $ax^2 + bx + c = 0$ is:

\begin{equation}
    x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
\end{equation}

This formula includes a square root: $\sqrt{b^2 - 4ac}$ which is called the discriminant.

\section{Other Examples}

Simple square root: $\sqrt{4} = 2$

Nested expression: $\sqrt{x^2 + y^2}$

Cube root: $\sqrt[3]{8} = 2$
