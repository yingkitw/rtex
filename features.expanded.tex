\section{Multi-line Equations}

Aligned equations use \texttt{align}:

\begin{align}
    a &= b + c \\
    d + e &= f + g + h \\
    i &= j
\end{align}

Gathered equations use \texttt{gather}:

\begin{gather}
    x = 1 \\
    y = 2 \\
    z = 3
\end{gather}

Multi-line single equation uses \texttt{multline}:

\begin{multline}
    a + b + c + d + e + f + g + h + i + j \\
    + k + l + m
\end{multline}

\section{Piecewise Functions}

Piecewise definitions can appear inside math delimiters:

\[
    f(x) = \begin{cases}
        x^2  & \text{if } x \geq 0 \\
        -x   & \text{if } x < 0
    \end{cases}
\]

or at the top level via \texttt{\textbackslash begin\{cases\}}.
