# Test Data

This directory contains test data files used for testing and development.

## Files

### `references.bib`
Bibliography file containing sample references for testing bibliography processing functionality.

### `simple_test.tex`
Simple LaTeX test document used for quick testing and validation.

## Usage

These files are used by:
- Unit tests for validating specific functionality
- Integration tests for end-to-end testing
- Development testing and debugging
- Performance benchmarking

## Adding New Test Data

When adding new test data files:
1. Use descriptive filenames that indicate their purpose
2. Keep files minimal and focused on specific test cases
3. Document the purpose of each file in this README
4. Ensure files are valid LaTeX/BibTeX syntax
