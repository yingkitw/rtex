Multi-line Equations

Aligned equations use align:

a&=b+ca = b + c
d+e&=f+g+hd + e = f + g + h
i&=ji = j

Gathered equations use gather:

x=1x = 1
y=2y = 2
z=3z = 3

Multi-line single equation uses multline:

a+b+c+d+e+f+g+h+i+ja + b + c + d + e + f + g + h + i + j
+k+l+m+ k + l + m

Piecewise Functions

Piecewise definitions can appear inside math delimiters:

f(x)=x2if x≥0f(x) = { x² if x ≥ 0
-xif x<0{ -x if x < 0

or at the top level via \textbackslash begin\{cases\}.
